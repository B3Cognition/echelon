# Reconstitute - Generate Strategic Migration Artifacts

> **Bash Command Guidelines**: Never use multi-line bash. Chain commands with `&&`. **IMPORTANT**: Do NOT use bash `ls`, `find`, `cat`, `echo`, or `grep` for file exploration - always use the dedicated Glob, Read, and Grep tools instead. Reserve bash only for git commands, `mkdir`, and other system operations.

Generate all strategic-level migration documents that bridge understanding (specs) and implementation (per-domain plans/tasks).

## Purpose

This command generates the **strategic layer** of migration artifacts:

1. **constitution.md** - Legacy analysis + target principles
2. **migration-strategy.md** - 6R/7R analysis, strangler fig assessment, wave planning
3. **risk-matrix.md** - Risk inventory with likelihood × impact
4. **gap-analysis.md** - Current vs target state gaps
5. **adrs/** - Architecture Decision Records for key choices

These artifacts inform the per-domain plan/tasks generation that follows.

## Prerequisites

1. Analysis has been run: `.specify/echelon/re/analysis.json` exists
2. Specifications have been generated: `specs/NNN-re-{domain}/` folders exist
3. Coverage verification complete (recommended ≥80%)

## User Input

$ARGUMENTS


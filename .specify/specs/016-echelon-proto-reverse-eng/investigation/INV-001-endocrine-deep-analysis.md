## Findings

### 1. Exact Content of Prompt Modifiers (Lines 809-882)

The `get_full_prompt_modifier` function reads all 6 hormone values and classifies each into three buckets: low [0.0, 0.35), medium [0.35, 0.75), high [0.75, 1.0]. For each hormone, it generates a brief text instruction prepended to the agent prompt:

**ADRENALINE**:
- LOW: "[ADRENALINE=LOW] Be thorough. Review all severity levels. Take your time."
- HIGH: "[ADRENALINE=HIGH] Focus only on CRITICAL and HIGH severity. Skip optional analysis. Prioritize speed."
- MEDIUM: (no modifier)

**DOPAMINE**:
- LOW: "[DOPAMINE=LOW] Your previous approach was rejected. Try a fundamentally different strategy."
- HIGH: "[DOPAMINE=HIGH] Your approach is working well. Build on your current strategy."
- MEDIUM: (no modifier)

**CORTISOL**:
- LOW: "[CORTISOL=LOW] You are in familiar territory. Make autonomous decisions confidently."
- HIGH: "[CORTISOL=HIGH] You are in unfamiliar territory. Be conservative. Escalate uncertainties. Add caveats to your output."
- MEDIUM: (no modifier)

**SEROTONIN**:
- LOW: "[SEROTONIN=LOW] Quality has been declining. Extra diligence required."
- HIGH: "[SEROTONIN=HIGH] Quality trajectory is strong. Maintain your current standard."
- MEDIUM: (no modifier)

**OXYTOCIN**:
- LOW: "[OXYTOCIN=LOW] Verify upstream agent's output thoroughly. Do not assume correctness."
- HIGH: "[OXYTOCIN=HIGH] Upstream agent has a strong track record. Focus your effort on new analysis rather than re-verifying their work."
- MEDIUM: (no modifier)

**NOREPINEPHRINE**:
- LOW: "[NOREPINEPHRINE=LOW] Explore broadly. Consider unconventional connections. Think laterally."
- HIGH: "[NOREPINEPHRINE=HIGH] Stay focused on the specific task. Do not explore tangents."
- MEDIUM: (no modifier)

Additionally, lines 884-899 show calibration injection: if `agent-scores.yaml` exists, the function appends a [CALIBRATION] block with historical failure modes and prior success patterns (Python-in-bash parsing of agent history).

**Critical observation**: The modifier text is deterministic, rule-based instruction tuning. There is no neural network, no learned parameters, no adaptation mechanism beyond the three-level classification.

### 4. Downstream Hormone Propagation (30%)

From endocrine.sh lines 27-28:
- `endocrine.sh propagate_downstream <from> <to> — propagate dopamine at 30% strength`

This is a literal 30% weighted sum: if agent A (upstream) has dopamine = 0.8, agent B (downstream) receives a +0.24 delta applied to its dopamine level (clamped to [0.0, 1.0], dampened per circuit breakers). There is no propagation graph specification in endocrine.sh itself; the graph would need to be defined by the caller (COMMANDER dispatch order).

**Implementation detail**: The propagation is bidirectional policy — it CAN be called for any downstream pair, but the actual call sites are not specified in the code. This is a capability, not a behavior, until explicit call sites are added.

### 5. Is This "Just Prompt Injection"?

**YES, structurally. But with quantified state dimensions.**

**How it IS standard prompt injection**:
- Text is prepended to the agent prompt at dispatch time
- The text is rule-based (deterministic classification into three levels)
- The injected instructions use natural language ("Be thorough," "Prioritize speed")
- No learned parameters, no neural adaptation

**How it DIFFERS from naive dynamic injection**:
1. **Quantified state space**: Hormones are scalar [0.0, 1.0] values, not binary on/off flags or categorical tags. This allows fine-grained tuning via baselines.
2. **Per-archetype baselines**: Not all agents receive the same hormone state; each archetype starts at a different baseline. This is role-specific, not global.
3. **Decay and circuit breakers**: Hormone levels do not simply accumulate; they decay exponentially per cycle (adrenaline 0.6×/cycle, serotonin 0.95×/cycle) and are clamped to prevent extreme oscillations.
4. **Multi-dimensional stimulus response**: Six independent modulation axes (urgency, motivation, vigilance, stability, collaboration, focus) are modulated simultaneously, creating a 6D behavioral state space.
5. **Phase-gating**: The system activates different hormone subsets based on phase, creating a staged rollout of complexity.
6. **Calibration loop**: The system collects hormone_history events in state.json and uses calibrate-endocrine.sh to analyze correlation between hormone levels and gate outcomes, proposing baseline adjustments. This is a feedback loop not present in static prompt injection.

**The honest assessment**: Endocrine is **engineered prompt injection with quantified state management, decay dynamics, and calibration feedback**. The biological metaphor is pedagogically useful but not technically required — the system could be called "motivation-modulation via six-dimensional scalar state" without losing any functional meaning. The novelty claim depends on whether "six-dimensional quantified scalar state + decay + calibration + phase-gating" is defensible as distinct from "smart prompt engineering."

### 6. Calibration Injection (Lines 884-899)

The endocrine system integrates with calibration data via SCOREKEEPER's `agent-scores.yaml` file. The `get_full_prompt_modifier` function reads prior agent history (success/failure rates, failure modes, run history) and appends a [CALIBRATION] block:

```
[CALIBRATION] COLD START — no prior data for <agent>.
[CALIBRATION] Failure modes from 5 runs: ...
[CALIBRATION] Success rate: X%.
```

This is the "calibration data injection" from spec 010. It bridges the hormone system with the learning loop: hormone baselines improve based on observed gate outcomes, via the calibrate-endocrine.sh script.

## Verdict

**PARTIALLY CONFIRMED / CHALLENGER**

The endocrine system is technically sophisticated engineering of dynamic prompt injection, not a qualitatively different mechanism. The claimed novelty is defensible on these grounds:

1. **Quantified state management**: Six scalar dimensions (not discrete categories) create a fine-grained behavioral state space. This enables gradient-based tuning and is more structured than ad-hoc prompting.

2. **Decay dynamics and circuit breakers**: The exponential decay rates per hormone and ceiling/floor constraints create temporal dynamics absent in static prompt injection. Serotonin's slow decay (0.95×/cycle) means quality baseline persists; adrenaline's fast decay (0.6×/cycle) means urgency is brief.

3. **Calibration feedback loop**: The system measures hormone-outcome correlations and proposes baseline adjustments. This is mechanized tuning, not manual prompt engineering.

4. **Phase-gating**: Staged activation of hormone subsets (Phase 1 = adrenaline; Phase 3 = all six) creates a deployment ramp. This is operational structure.

**However**, the core mechanism remains prompt text injection. The prompt modifiers are rule-based, deterministic instructions ("Be thorough," "Prioritize speed"). If the prior art includes any system with:
- Multi-dimensional state modulation to agent behavior,
- Decay dynamics on state dimensions,
- Feedback loops that tune state baselines based on outcomes,

then Echelon's claim to novelty is WEAKENED. The novelty catalogue asserts "no existing framework implements continuous hormone-like modulation with phase-gating, decay, and propagation" — but this is a narrow claim. CrewAI or AutoGen may not call it "hormones," but they might have state-modulation mechanisms that are functionally equivalent.

**Recommendation**: Conduct a targeted search for "agent state decay," "multi-dimensional agent behavior modulation," or "feedback-tuned agent baselines" in prior frameworks. If zero results, the claim holds. If any results exist, determine whether they achieve the same effect through different terminology.

# Evidence Grades

Use this scale when ranking research, benchmarks, operational data, or recommendation evidence.

| Grade | Source quality | Use |
|-------|----------------|-----|
| A | Peer-reviewed research, ISO/IEEE/NIST standards, directly measured production data | Strong basis for decisions |
| B | Official vendor/framework docs, reproducible benchmarks, validated experiments | Good basis for decisions |
| C | Reputable engineering blogs, conference talks, case studies, postmortems | Useful supporting evidence |
| D | Forum posts, Stack Overflow, anecdotal reports, single-run observations | Weak evidence; corroborate before relying |
| E | Unverified model knowledge, guesses, stale memory, unsupported claims | Do not use alone for decisions |

Always cite the source, date or version, and confidence impact. If evidence conflicts, prefer higher grade; for equal grade, prefer newer or more directly applicable evidence.

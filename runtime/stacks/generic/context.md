# Generic discovery

Technology is explicitly undecided. Framework and package-manager choice remain
open during discovery. This stack grants no verification or runtime capabilities.

ALWAYS resolve concrete owner-selected verification capabilities before declaring
a spec ready for Delivery. Compose generic with suitable capability stacks, or
replace it with a concrete/custom stack.
NEVER treat generic as evidence that tests can run, that a visual validator is
available, or that a product is non-runnable. Never silently select a framework.

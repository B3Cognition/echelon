# Glossary — Checkout (approved terms)

- **Checkout_Service**: service that processes cart checkout
- **cart**: the shopper's set of items to purchase
- **payment_intent**: a created intent to charge the shopper
- **order_total**: the total amount due for the cart
- **Payment_Gateway**: external service that charges payment
- **order_status**: lifecycle state of an order
- **payment_status**: lifecycle state of a payment
- **order_confirmation_email**: email sent after a successful order
- **PAYMENT_DECLINED**: error code when the gateway declines the charge
- **INSUFFICIENT_FUNDS**: error code when the shopper has insufficient funds

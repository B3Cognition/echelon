# Glossary — Catalog search (approved terms)

- **Search_Service**: service that answers catalog search queries
- **search_query**: the text and filters a user searches with
- **result_page**: one page of search results
- **page_size**: the number of results per result_page
- **result_count**: the total number of matching results
- **filter_set**: the set of filters applied to a search_query
- **sort_order**: the ordering applied to results
- **search_status**: lifecycle state of a search_query
- **QUERY_TOO_LONG**: error code when a search_query exceeds the length limit
